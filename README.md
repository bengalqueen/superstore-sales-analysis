# Superstore Sales Analysis 
## Project Overview
Analyzed 9,694 records of a retail superstore to identify sales trends, 
regional performance, and profitability insights.
## Tools Used
- **MySQL** — Data analysis & querying
- **Power BI** — Interactive dashboard
- **Excel** — Dataset
## Key Insights
- Technology category generates highest revenue (₹8,35,900)
- High discounts (40%+) cause loss of ₹98,327
- Texas ranks 3rd in sales but has ₹25,534 loss
- Q4 (Nov-Dec) is consistently the strongest quarter
- California is the top performing state
## SQL Queries Performed
1. Category wise sales analysis
2. Region wise performance
3. Monthly sales trend
4. Discount impact on profit
5. Top 10 customers by profit
6. Sub-category performance
7. Running total (Window Function)
8. State wise sales ranking (RANK function)
